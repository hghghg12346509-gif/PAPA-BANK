Как пользоваться «Папа-банк PRO»?
  • + / − — выберите тип операции, заполните сумму и нажмите «Добавить». Можно писать сумму прямо в поле и жать Enter.
  • Колонка Итог — скользящий баланс: каждая строка прибавляет/вычитает свою сумму к предыдущей.
  • Таблица группируется по месяцам: в заголовке группы сразу видны плюсы, минусы и итог месяца.
  • Двойной клик по строке — редактирование записи, кнопки ✏️ и 🗑 — в колонке действий.
  • Экспорт CSV — файл для Excel (с русскими буквами). Импорт CSV — загрузка обратно, дубли отсекаются.
  • Бэкап / Восстановить — полная копия данных в JSON-файле.
  • Горячие клавиши: N — сумма, / — поиск, Ctrl+Z — отмена, T — тема, Esc — закрыть окно.
  • Все данные хранятся только в вашем браузере. Кнопка «Очистить всё» удаляет записи (но их можно вернуть через «Отменить»).
